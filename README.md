# 📊 DataView

Aplicación móvil desarrollada con **Flutter** para la visualización e interpretación de datos mediante gráficos interactivos.

## 🚀 Descripción

**DataView** permite presentar información de manera visual y sencilla, facilitando la comprensión de diferentes conjuntos de datos mediante gráficos y elementos interactivos.

El proyecto fue desarrollado como parte del proceso académico de **Ingeniería de Sistemas**.

## 🛠️ Tecnologías utilizadas

* Flutter
* Dart
* Material Design
* Visual Studio Code
* Git y GitHub

## 📱 Funcionalidades

* Visualización de datos mediante gráficos.
* Interfaz sencilla e intuitiva.
* Navegación entre las diferentes secciones de la aplicación.
* Presentación visual de información para facilitar su análisis.

## ⚙️ Instalación

Para ejecutar el proyecto localmente:

1. Clonar el repositorio:

```bash
git clone URL_DE_TU_REPOSITORIO
```

2. Entrar a la carpeta:

```bash
cd DataView
```

3. Instalar las dependencias:

```bash
flutter pub get
```

4. Ejecutar la aplicación:

```bash
flutter run
```
